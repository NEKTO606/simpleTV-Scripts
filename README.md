<b>Перечень и пути к файлам LimeHD:</b>

скрапер TVS: /luaScr/user/TVSources/scrapers/lime_hd_pls.lua<br>
скрипт запуска ивента: /luaScr/user/startup/lime_start.lua<br>
скрипт ивента: /luaScr/user/lime/events.lua<br>
видеоскрипт: /luaScr/user/video/limeHD.lua<br>
расширение дополнения httptimeshift: /luaScr/user/httptimeshift/extensions/limehd-timeshift_ext.lua

Для работы источника LimeHD необходимо наличие скриптов <b>LuaSocket</b> в сборке Симпла. Если их нет скачать по <a target="_blank" href="https://disk.yandex.ru/d/c3ueDUXIxTHjbQ">ссылке</a> архив и распаковать в корень программы.
